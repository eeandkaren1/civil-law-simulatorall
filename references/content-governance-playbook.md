# 民法鎮大冒險：內容治理作業手冊

## 適用範圍與角色

本手冊適用於所有公開題目、法條摘要、法律知識文章、村落導讀與未來App內容。平台定位為法律教育，不是個案法律諮詢；任何可能影響讀者判斷的法律效果，都應標示法源、核對日期及教育用途。公開內容的責任鏈必須可追溯至一位內容負責人，即使撰寫或格式整理使用了輔助工具亦然。

| 角色 | 最低責任 | 不可省略的紀錄 |
|---|---|---|
| 內容撰寫者 | 撰寫原創情境、解析與文章；避免複製法源或其他網站的表述 | 內容ID、草稿日期、使用的法源連結 |
| 法源核對者 | 逐條核對現行條文、修正狀態與題目法律效果 | 官方網址、核對日期、差異說明、核對人 |
| 發布責任人 | 確認頁面正文、連結、SEO摘要、圖片權利與教育聲明 | 發布日期、版本號、頁面網址、圖片來源／授權 |
| 數據與產品責任人 | 依匯總資料判斷內容需求，不以不當點擊或個資追蹤營利 | 檢視週期、指標、決策紀錄、改善項目 |

## 新題目與文章的發布清單

每一項公開內容先在草稿狀態完成，再經過以下順序後發布。若任一項不成立，應保留為草稿或下架複核，不能以「先上線、日後更正」取代核對。

| 檢查階段 | 題目必填項 | 文章必填項 | 放行條件 |
|---|---|---|---|
| 內容原創性 | 生活情境、題幹、4個具鑑別度選項、逐項解析、申論與提示 | 問題意圖、原創解說、清楚結論與相關練習連結 | 不與既有內容重複核心法律效果或大量改寫他人內容 |
| 法源正確性 | 條文號、法務部現行條文連結、最後核對日 | 引用法源與具體適用範圍 | 條文文字、修正狀態及結論均已核對 |
| 讀者保護 | 教育用途、非個案諮詢提示；避免過度斷言 | 同左；必要時標示時間、條件與例外 | 不使讀者誤以為內容已取代專業法律意見 |
| 可索引性 | 唯一ID、題名、摘要、村落、相關法條、前後題連結 | 唯一slug、作者／責任編輯、摘要、日期、相關題目 | 確認SSR正文、title、description與canonical可產生 |
| 權利與廣告 | 圖片來源與授權；廣告不得干擾選項或答案 | 圖片來源與授權；廣告不得多於正文或誤導導航 | 符合隱私、版權與廣告政策 |

## 資料版本與App共用原則

公開內容與使用者進度要分開管理。題目、文章與法條的每一次實質更新都應提升內容版本；網站與App讀取同一個已發布版本。使用者的作答、錯題與偏好則應在明確告知與同意後才同步，且不得直接混入廣告或分析請求。

```text
Content record → Draft → Legal review → Published version → Web SSR / Sitemap / App API
Learner record → Local progress → Optional account sync → Learning analytics (aggregated)
```

建議將下列欄位加入未來的內容管理來源：`status`、`contentVersion`、`sourceUrls`、`lastVerifiedAt`、`reviewedBy`、`changeSummary`、`publishedAt`、`seoTitle`、`seoDescription`。現有的 `id` 必須永久穩定，以避免搜尋頁面、外部連結及App深層連結在更新後失效。

## 修法、錯誤回報與下架機制

法源變動時，先以官方來源列出受影響的條文與題目，再將相關內容改為「待複核」。涉及基本法律效果或可能誤導讀者的頁面，應先在公開頁標示更新中或暫時下架，不宜等待下個月批次。任何錯誤回報都應在工作表留下受理日期、影響範圍、處理結論與發布版本。

| 事件 | 處理時限目標 | 必要動作 |
|---|---:|---|
| 明確的法條修正或失效 | 發現後1個工作日內完成影響盤點 | 建立複核清單、更新法源、確認受影響URL |
| 可能誤導法律效果的錯誤 | 優先處理 | 標示／暫停內容、修正並留下版本摘要 |
| 排版、連結或SEO錯誤 | 下一個維護週期 | 修復後檢查SSR、網站地圖與404回應 |
| 讀者意見或新增題材需求 | 每月彙整 | 以需求、教育價值與核對成本決定優先順序 |

## 廣告與分析護欄

廣告需是內容之後的輔助收入，而非導覽或作答流程的一部分。不得要求讀者點擊廣告、以獎勵交換廣告瀏覽、或以自動／人工方式放大曝光與點擊。應定期檢視行動版，確認廣告不與選項、下一題按鈕、主選單或返回連結相鄰到容易誤點；隱私權政策也應隨分析、廣告或帳戶同步功能變更一併更新。[1]
