# 親屬村第二批：離婚損害、收養效力與親權保護官方查核摘要

| 條號 | 現行條文要旨 | 題目方向 |
|---|---|---|
| 第1056條 | 因判決離婚受有損害者得向有過失他方請求賠償；無過失受害人得請求非財產損害賠償。 | 判決離婚後向有責配偶請求財產及精神損害。 |
| 第1077條 | 養子女與養父母及其親屬關係原則與婚生子女同；收養存續中與本生父母及其親屬的權利義務停止。 | 收養後與養家／本生家庭的權利義務。 |
| 第1090條 | 父母一方濫用子女權利時，法院可為子女利益宣告停止全部或一部權利。 | 濫用親權時的法院保護。 |
| 第1092條 | 父母得因特定事項、於一定期限內，以書面委託他人行使監護職務。 | 父母長期出國時，以書面委託祖母處理子女就醫等特定事項。 |
| 第1118條 | 扶養義務人因負擔扶養義務不能維持自己生活者，免除義務；但直系血親尊親屬受扶養時，減輕其義務。 | 扶養義務人自身生活難維持時的免除與減輕。 |

> 第1015條已刪除，不納入題庫。第1090條以未成年子女最佳利益下的親權停止為核心，與既有離婚後監護改定題目不重複。
