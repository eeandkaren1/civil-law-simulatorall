# 物權村第二批：取得時效中斷與相鄰關係官方查核摘要

| 條號 | 條文要旨 | 生活化題目方向 |
|---|---|---|
| 第771條 | 所有權取得時效於特定占有狀態改變、停止或所有人依第767條起訴返還時中斷。 | 占有人被所有人起訴返還，時效是否繼續。 |
| 第773條 | 土地所有權及於上下有利益範圍；無礙行使的干涉不得排除。 | 鄰地高空設備是否真正妨礙土地利用。 |
| 第774條 | 土地所有人經營事業或行使所有權應注意防免鄰地損害。 | 施工震動或店家排煙造成鄰地損害。 |
| 第775條 | 土地所有人不得妨阻鄰地自然流入之水；鄰地所必需者，不得全部妨阻。 | 低地鄰居自然排水遭圍牆阻擋。 |
| 第776條 | 蓄水、排水或引水工作物破潰、阻塞造成或有造成鄰地損害之虞，土地所有人原則上應自費修繕、疏通或預防。 | 私設排水管堵塞倒灌鄰地時的修繕義務。 |
