# 親屬村第一批：婚姻效力、子女財產與扶養官方查核摘要

| 條號 | 現行條文要旨 | 題目方向 |
|---|---|---|
| 第1001條 | 夫妻互負同居義務；有不能同居正當理由者例外。 | 因安全或工作等正當理由暫不共同居住。 |
| 第1018條 | 夫或妻各自管理、使用、收益及處分其財產。 | 一方自行處分自己名下存款。 |
| 第1050條 | 兩願離婚須書面、二人以上證人簽名及戶政登記。 | 僅簽離婚協議未登記的效力。 |
| 第1088條 | 未成年子女特有財產由父母共同管理；僅為子女利益才可處分。 | 父母出售子女受贈股票以償自己的債。 |
| 第1117條 | 受扶養權利者原則不能維持生活且無謀生能力；直系血親尊親屬不受無謀生能力限制。 | 有微薄工作能力但生活無法維持的年長父母。 |

> 第1020條已刪除，不納入題庫。第1031條為共同財產制規定；為避免將共同財產制誤當成未約定時的法定財產制，本批不以其為核心題目。
