# 總則村第一批 5 題：官方法條查核

本批審核稿使用法務部全國法規資料庫《民法》單條頁面核對，僅供民法教育使用；個案仍應依具體事實與最新法規判斷。

| 題號 | 核心爭點 | 查核條文與重點 | 官方來源 |
|---|---|---|---|
| G-21 | 簽名、印章與指印 | 文字可不由本人自寫但須親自簽名；印章代簽名與簽名同效；指印等符號須有二人簽名證明。 | <https://law.moj.gov.tw/LawClass/LawSingle.aspx?pcode=B0000001&flno=3> |
| G-22 | 文字與號碼不一致 | 就數量同時以文字與號碼表示而不一致時，若法院不能決定真意，應以文字為準。 | <https://law.moj.gov.tw/LawClass/LawSingle.aspx?pcode=B0000001&flno=4> |
| G-23 | 從物 | 非主物成分、常助主物效用且同屬一人者為從物；主物處分及於從物，但交易習慣另有規定者從其習慣。 | <https://law.moj.gov.tw/LawClass/LawSingle.aspx?pcode=B0000001&flno=68> |
| G-24 | 天然／法定孳息 | 果實、動物產物與依物用法收穫者為天然孳息；利息、租金及因法律關係所得收益為法定孳息。 | <https://law.moj.gov.tw/LawClass/LawSingle.aspx?pcode=B0000001&flno=69> |
| G-25 | 非對話意思表示的到達 | 非對話意思表示於通知到達相對人時生效；撤回通知同時或先到達者例外；發出通知後死亡或行為能力變動，原意思表示不因此失效。 | <https://law.moj.gov.tw/LawClass/LawSingle.aspx?pcode=B0000001&flno=95> |

## 下一批候選爭點（尚未整合）

| 候選爭點 | 條文與官方來源 |
|---|---|
| 多次數量表示不一致 | 民法第 5 條：以文字或號碼為數次表示而不符合，無法決定真意時以最低額為準。<https://law.moj.gov.tw/LawClass/LawSingle.aspx?pcode=B0000001&flno=5> |
| 失蹤人的死亡宣告 | 民法第 8 條：一般失蹤滿七年、八十歲以上者滿三年、特別災難終了滿一年，法院得依聲請為死亡宣告。<https://law.moj.gov.tw/LawClass/LawSingle.aspx?pcode=B0000001&flno=8> |
| 住所設定 | 民法第 20 條：依一定事實足認有久住意思而住於一定地域，即設定住所；一人同時不得有兩住所。<https://law.moj.gov.tw/LawClass/LawSingle.aspx?pcode=B0000001&flno=20> |
| 法定代理人住所 | 民法第 21 條：無行為能力人、限制行為能力人以其法定代理人住所為住所。<https://law.moj.gov.tw/LawClass/LawSingle.aspx?pcode=B0000001&flno=21> |
| 法人成立 | 民法第 25 條：法人非依民法或其他法律規定不得成立。<https://law.moj.gov.tw/LawClass/LawSingle.aspx?pcode=B0000001&flno=25> |
| 法人的權利能力 | 民法第 26 條：法人於法令限制內，有享受權利、負擔義務能力；專屬自然人的權利義務除外。<https://law.moj.gov.tw/LawClass/LawSingle.aspx?pcode=B0000001&flno=26> |
| 董事代表權 | 民法第 27 條：董事對外代表法人；代表權限制不得對抗善意第三人。<https://law.moj.gov.tw/LawClass/LawSingle.aspx?pcode=B0000001&flno=27> |
| 法人連帶賠償 | 民法第 28 條：法人對代表人執行職務加於他人的損害，與行為人連帶負賠償責任。<https://law.moj.gov.tw/LawClass/LawSingle.aspx?pcode=B0000001&flno=28> |
| 法人住所 | 民法第 29 條：法人以主事務所所在地為住所。<https://law.moj.gov.tw/LawClass/LawSingle.aspx?pcode=B0000001&flno=29> |
| 法人登記 | 民法第 30 條：法人非經向主管機關登記不得成立。<https://law.moj.gov.tw/LawClass/LawSingle.aspx?pcode=B0000001&flno=30> |
| 法人財產不足 | 民法第 35 條：法人財產不能清償債務時，董事應即向法院聲請破產；有過失未聲請致債權人受損，應負賠償責任。<https://law.moj.gov.tw/LawClass/LawSingle.aspx?pcode=B0000001&flno=35> |
| 法人解散 | 民法第 36 條：法人目的或行為違反法律、公共秩序或善良風俗時，法院得依請求宣告解散。<https://law.moj.gov.tw/LawClass/LawSingle.aspx?pcode=B0000001&flno=36> |
| 法人清算 | 民法第 37 條：法人解散後，原則上由董事清算；章程或總會另有規定者從其規定。<https://law.moj.gov.tw/LawClass/LawSingle.aspx?pcode=B0000001&flno=37> |
| 法院選任清算人 | 民法第 38 條：無法依第 37 條定清算人時，法院得依聲請或職權選任。<https://law.moj.gov.tw/LawClass/LawSingle.aspx?pcode=B0000001&flno=38> |
| 一般請求權時效 | 民法第 125 條：請求權原則上因十五年不行使而消滅，法律另有較短期間者從其規定。<https://law.moj.gov.tw/LawClass/LawSingle.aspx?pcode=B0000001&flno=125> |
| 定期給付時效 | 民法第 126 條：利息、紅利、租金、贍養費、退職金及其他一年或不及一年定期給付，其各期請求權五年不行使而消滅。<https://law.moj.gov.tw/LawClass/LawSingle.aspx?pcode=B0000001&flno=126> |
