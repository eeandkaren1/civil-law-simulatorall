# 物權村第一批：所有權與取得時效官方條文查核摘要

本批候選於 2026-08-24 依全國法規資料庫核對。

| 條號 | 現行條文要旨 | 題目方向 |
|---|---|---|
| 第765條 | 所有人於法令限制內，得使用、收益、處分所有物，並排除他人干涉。 | 車位所有人受無權占用時的所有權權能。 |
| 第767條 | 所有人得請求無權占有人返還、請求除去妨害及防止妨害之虞。 | 鄰居堆物侵占私有走道的返還／除去／防止請求。 |
| 第768條 | 以所有意思十年和平、公然、繼續占有他人動產者，取得所有權。 | 長期以所有意思管理遺留腳踏車。 |
| 第769條 | 以所有意思二十年和平、公然、繼續占有他人未登記不動產者，得請求登記為所有人。 | 長期占有未登記農地的請求登記。 |
| 第770條 | 以所有意思十年和平、公然、繼續占有他人未登記不動產，且占有開始為善意無過失者，得請求登記為所有人。 | 誤信買受未登記土地後長期善意占有。 |
