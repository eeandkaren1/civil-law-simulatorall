# 債編村第三批：連帶債務官方條文查核摘要

本批候選主題以多人共同負債與連帶債務為核心，均於 2026-08-24 依全國法規資料庫核對。

| 條號 | 官方條文要旨 | 預定生活情境 |
|---|---|---|
| 第271條 | 多人負可分的同一債務，除法律或契約另定外，各平均分擔。 | 三名室友未約定連帶，合租設備費應如何分擔。 |
| 第273條 | 連帶債務債權人得向一人、數人或全體，請求全部或一部給付。 | 兩名共同借款人約定連帶責任，銀行向其中一人求償。 |
| 第278條 | 債權人對連帶債務人之一人有遲延時，對其他債務人亦生效力。 | 債權人無正當理由拒收其中一位連帶債務人的清償。 |
| 第281條 | 一名連帶債務人清償使他人同免責時，可向他人求償各自分擔部分及利息。 | 共同承租人中一人清償全部欠租後的內部分攤。 |
| 第287條 | 連帶債權人中之一人受有利益的確定判決，對其他債權人亦生效；不利益判決原則上亦及於他人，但個人關係原因除外。 | 兩名共同受款人中一人先取得確定判決時，另一人的效力問題。 |
