# AdSense 上線準備檢核（2026-08）

## 判讀原則

本檢核以使用者提供的 GA4 首頁截圖為觀察基礎：過去七天顯示 **119 位活躍使用者、115 位新使用者與 1,201 次事件**。這些數字可用來建立後續追蹤基線，但不能獨立推論網站一定會獲得或不會獲得 AdSense 核准。Google 公開的計畫政策重點在內容、流量品質與廣告互動規範，而非列出固定的最低訪客數；申請結果仍由 Google 個案審核。[1]

| 面向 | 目前狀態 | 申請前仍須確認的行動 |
|---|---|---|
| 實質原創內容 | 已具備 200 道具法條解析、選項理由與申論引導的題目，以及 20 篇文章。 | 以每月法條核對、作者／編輯覆核與修訂紀錄維持原創性；避免只產生短篇、改寫或重複頁。 |
| 可探索頁面 | 題目、文章與五個村落皆有公開穩定網址；題目正文已由伺服器直接輸出。 | 正式網域完成後，設定 `CANONICAL_ORIGIN`，提交 sitemap 至 Search Console，等待可索引狀態。 |
| 使用者體驗 | 已有村落導覽、搜尋、每日挑戰、錯題本、分享與收藏。 | 以行動版實測確認廣告不遮擋作答、分享、收藏及法條正文；不要在低資訊密度處堆放廣告。 |
| 法律與信任頁 | 網站既有隱私權、服務條款、關於與聯絡入口。 | 發布前逐頁檢查聯絡信箱、教育用途／非個案法律意見聲明與資料使用說明是否可直接找到。 |
| 流量品質 | 截圖顯示近期新增訪客與事件有上升。 | 不購買流量、不點擊自己廣告、不要求使用者點廣告，也不使用機器人或誤導方式提高曝光／點擊。[1] |
| 網站所有權 | 尚未決定正式網域。 | 擁有正式網址後，依 Search Console 的驗證方式完成所有權驗證，再把該網址用於 AdSense 與搜尋成效追蹤。[2] |

> **結論：** 現有流量不是明顯的技術障礙，也不是核准保證。以目前內容品質與已完成的獨立題目頁架構，可先累積正常的自然流量與使用訊號；正式網域、索引設定、全面頁面檢查及不造假流量，是實際送審前的優先條件。

## 建議的申請時點

在正式網域啟用、網站地圖可讀取、Search Console 完成驗證並確認主要公開頁可被檢索後，再送出申請較為穩妥。提交前至少以手機、桌機各檢視首頁、五個村落、數個題目頁、文章頁與四個信任頁；若有廣告碼，亦應檢查它未妨礙主要學習互動。這是風險管理建議，不是對核准結果或廣告收入的承諾。
