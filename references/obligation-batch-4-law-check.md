# 債編村第四批：債權讓與與債務承擔官方條文查核摘要

本批候選已於 2026-08-24 依全國法規資料庫核對。

| 條號 | 現行條文要旨 | 題目方向 |
|---|---|---|
| 第294條 | 債權原則上得讓與第三人；性質不得讓與、特約不得讓與及禁止扣押者例外；不得讓與特約不得對抗善意第三人。 | 原債權人出售已到期帳款。 |
| 第297條 | 債權讓與未由讓與人或受讓人通知債務人，對債務人不生效；提示讓與字據與通知同效。 | 債務人未收到帳款讓與通知仍向原債權人付款。 |
| 第301條 | 第三人與債務人約定承擔債務，未經債權人承認，對債權人不生效。 | 新屋主承諾承擔前屋主社區費，但管理委員會尚未承認。 |
| 第304條 | 從屬債權權利不因債務承擔妨礙存在；第三人提供的擔保，除第三人承認債務承擔外，因債務承擔消滅。 | 債務承擔後的擔保存續問題。 |
| 第305條 | 概括承受他人營業資產負債者，對債權人通知或公告後生債務承擔效力；原債務人對到期或到期後兩年內債權，與承擔人連帶負責。 | 店家整體轉讓後，原店主與新業者的兩年連帶責任。 |
