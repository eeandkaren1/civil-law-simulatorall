# 物權村第三批：排水與水源相鄰關係官方查核摘要

| 條號 | 條文要旨 | 題目方向 |
|---|---|---|
| 第779條 | 排泄家用或其他用水可通過鄰地，但須選擇損害最少處所與方法，並支付償金。 | 排水管必須經鄰地時的最小損害與補償。 |
| 第781條 | 水源地、井、溝渠及其他水流地所有人原則得自由使用其水。 | 私有井水的使用權與法令、習慣限制。 |
| 第782條 | 他人杜絕、減少或污染水源，水源所有人得請求賠償；必要時得請求回復原狀。 | 施工污染飲用井水。 |
| 第783條 | 因家用或土地利用必要且非過鉅費勞不能得水者，可付償金請求鄰地給與餘水。 | 缺水農地向鄰地購取餘水。 |
| 第784條 | 水流地對岸屬他人時，水流地所有人不得變更水流或寬度；兩岸均屬自己時亦應留下游自然水路。 | 私自加寬溪溝、改變水流影響對岸土地。 |
