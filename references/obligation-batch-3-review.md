# 債編村第三批：可分債務與連帶債務審核稿

本批預定新增 **obligation-031 至 obligation-035**。題目依序區分可分債務的平均分擔、連帶債務對外責任、債權人受領遲延對連帶債務人的效力、連帶債務人清償後的內部求償，以及連帶債權人判決效力。所有核心條文均已在全國法規資料庫核對。[1] [2] [3] [4] [5]

| 題號 | 情境 | 正確法律效果 |
|---|---|---|
| obligation-031 | 三人未約定連帶共同購買可分的社區清潔服務 | 除法律或契約另定外，應各平均分擔可分債務。 |
| obligation-032 | 兩名共同借款人明定連帶責任，銀行向其中一人請求全額 | 債權人得向一人、數人或全體請求全部或一部給付。 |
| obligation-033 | 債權人無正當理由拒收一名連帶債務人的完整清償 | 對其中一人受領遲延，為其他債務人利益亦生效力。 |
| obligation-034 | 一名共同承租人清償全部欠租，使其他人免責 | 清償人得向其他債務人求償各自分擔部分及利息。 |
| obligation-035 | 連帶債權人之一先取得有利確定判決 | 有利確定判決為其他連帶債權人的利益亦生效力。 |

> 本批特別避免把「多人負債」一概當連帶責任；第271條的可分債務平均分擔與第273條的連帶債務全額請求，必須由法律或契約事實加以區分。
