# 繼承村第二批：遺產債務與遺產分割官方查核摘要

| 條號 | 現行條文要旨 | 題目方向 |
|---|---|---|
| 第1153條 | 繼承人對被繼承人債務，以因繼承所得遺產為限負連帶責任；內部按應繼分比例負擔。 | 債權人請求與繼承人內部負擔的區分。 |
| 第1157條 | 遺產清冊陳報後，法院公告命債權人於一定期限內報明債權；期限不得少於三個月。 | 遺產債權公示催告的最短期限。 |
| 第1158條 | 繼承人在前條期限內，不得對任何被繼承人債權人償還債務。 | 不能搶先清償個別債權人。 |
| 第1165條 | 遺囑定有分割方法或託他人代定者從之；遺囑禁止分割效力以十年為限。 | 遺囑禁止分割的最長期間。 |
| 第1166條 | 胎兒為繼承人時，非保留其應繼分不得分割；胎兒關於遺產分割由母代理。 | 懷孕中的繼承人與遺產分割保留。 |
