# 親屬村第三批：離婚贍養、收養與監護官方查核摘要

| 條號 | 現行條文要旨 | 題目方向 |
|---|---|---|
| 第1057條 | 無過失配偶因判決離婚陷於生活困難，另一方縱無過失仍應給與相當贍養費。 | 判決離婚後的相當贍養費，與第1056條損害賠償區分。 |
| 第1076條之2 | 七歲以下被收養者由法定代理人代為並代受意思表示；七歲以上未成年人收養須法定代理人同意。 | 十歲孩童收養的法定代理人同意。 |
| 第1093條 | 最後行使、負擔未成年子女權利義務的父或母得以遺囑指定監護人；監護人知悉後十五日內應報告法院。 | 單親家長遺囑指定監護人與就職報告。 |
| 第1100條 | 監護人應以善良管理人注意執行監護職務。 | 監護人處理未成年被監護人財產的注意義務。 |
| 第1101條 | 監護人非為受監護人利益不得使用或處分其財產；代理購置或處分不動產等重要行為，非經法院許可不生效力。 | 監護人出售受監護人不動產的法院許可。 |
