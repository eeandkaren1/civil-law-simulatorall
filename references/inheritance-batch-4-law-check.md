# 繼承村第四批：拋棄繼承與繼承人不明官方查核摘要

| 條號 | 現行條文要旨 | 題目方向 |
|---|---|---|
| 第1174條 | 繼承人得拋棄繼承；知悉得繼承起三個月內以書面向法院為之，並書面通知因拋棄而應繼承者。 | 以口頭或私下協議拋棄與正確程序的區別。 |
| 第1175條 | 繼承拋棄溯及於繼承開始時發生效力。 | 成功拋棄後的溯及效力。 |
| 第1176條 | 拋棄人的應繼分依順位與身分歸屬其他繼承人；因他人拋棄而成為繼承人者，知悉起有三個月拋棄期間。 | 配偶與第一順序子女共同繼承時，子女拋棄的份額歸屬。 |
| 第1177條 | 繼承開始時繼承人有無不明，親屬會議一個月內選定遺產管理人並向法院報明。 | 找不到繼承人時，親屬會議的期限與報明義務。 |
| 第1179條 | 遺產管理人應編清冊、保存遺產、以一年以上期間催告債權人與受遺贈人、清償債權或交付遺贈物、移交遺產；清冊三個月內編製，並先清償債權再交付遺贈物。 | 遺產管理人先還債或先交付遺贈物的順序。 |

## 不採用條文

- 第1178條的六個月以上繼承人公示催告，與第1177條的繼承人不明管理情境密切相連，為避免本批核心爭點重複而暫不採用。
- 第1181條屬管理人催告期內禁止清償或交付，與第二批第1158條的禁止提前清償核心效果接近，暫不採用。
