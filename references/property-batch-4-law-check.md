# 物權村第四批：通水、管線與袋地通行官方條文查核摘要

本批候選均已於 2026-08-24 依法務部全國法規資料庫核對。

| 條號 | 現行條文要旨 | 題目方向 |
|---|---|---|
| 第785條 | 水流地所有人設堰有必要時得附著對岸，但須補償對岸損害；對岸地所有人於一定條件下得使用並分擔費用。 | 灌溉堰必須固定於對岸時的補償。 |
| 第786條 | 非通過他人土地不能設置或費用過鉅時，得於損害最少方法設電線、水管、瓦斯等管線並付償金。 | 住宅水管必須經過鄰地。 |
| 第787條 | 土地無適宜聯絡公路致不能通常使用，且非所有人任意行為所致，可通行周圍地；須採最小損害並付償金。 | 袋地通行權。 |
| 第788條 | 有通行權人必要時得開設道路並付償金；損害過鉅時通行地所有人得請求購買通行地及畸零地。 | 袋地通行開路造成重大損害。 |
| 第789條 | 因分割、讓與或其他土地交易致一部土地不通公路者，所有人僅得通行讓與人的土地，且原則無須償金。 | 分割後形成袋地的特別通行規則。 |
