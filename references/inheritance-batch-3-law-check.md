# 繼承村第三批：遺產分割後擔保與扣還官方查核摘要

| 條號 | 現行條文要旨 | 題目方向 |
|---|---|---|
| 第1168條 | 遺產分割後，各繼承人按所得部分，就他繼承人因分割取得的遺產，負與出賣人同一擔保責任。 | 分到的車輛有他人權利主張時，其他繼承人的擔保。 |
| 第1169條 | 遺產分割後，各繼承人按所得部分，就他繼承人因分割取得債權，擔保分割時債務人的支付能力；附停止條件或未到期債權，改以應清償時支付能力為準。 | 分到亡者對他人借款債權時，債務人資力的判斷時間。 |
| 第1170條 | 對第1168、1169條擔保責任中無支付能力者的不能償還部分，原則由有請求權人與其他繼承人按所得比例分擔；因請求權人過失所致者例外。 | 擔保責任人無資力時的風險分配。 |
| 第1172條 | 繼承人對被繼承人負債時，遺產分割應按債務數額從其應繼分扣還。 | 生前借款給子女，在分產時自其應繼分扣還。 |
| 第1173條 | 繼承人因結婚、分居或營業曾受財產贈與，原則將贈與價額加入應繼遺產，並從其應繼分扣除；被繼承人明示反對者例外；價額按贈與時價值計算。 | 父母資助結婚或創業的特種贈與與扣還。 |

## 不採用條文

- 第1167條已刪除，不作題庫依據。
- 第1171條仍涉及遺產債務的連帶責任，與第二批第1153條的核心效果接近，留待後續需要時再評估。
- 第1174條的繼承拋棄期限與書面法院程序，保留為第四批題材。
