# 繼承村第一批：繼承順位、代位與遺產共有官方查核摘要

| 條號 | 現行條文要旨 | 題目方向 |
|---|---|---|
| 第1138條 | 配偶外的遺產繼承人順位為：直系血親卑親屬、父母、兄弟姊妹、祖父母。 | 有子女時兄弟姊妹不得越過第一順位主張。 |
| 第1140條 | 第一順位繼承人在繼承開始前死亡或喪失繼承權，由其直系血親卑親屬代位繼承其應繼分。 | 先亡子女的孫子女代位。 |
| 第1141條 | 同一順序繼承人數人時，按人數平均繼承，法律另有規定者除外。 | 兩位子女同順位平均分配。 |
| 第1151條 | 多位繼承人在遺產分割前，對遺產全部公同共有。 | 其中一人不得將整筆遺產視為自己單獨所有。 |
| 第1152條 | 前條公同共有的遺產，得由繼承人中互推一人管理。 | 多繼承人互推一人管理遺產房屋。 |
