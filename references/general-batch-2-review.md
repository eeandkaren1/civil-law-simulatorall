# 總則村第二批 5 題審核稿

本批尚未整合網站，法條均以全國法規資料庫核對。

## G-26｜報價單寫了三種金額

阿隆的裝潢報價單，針對同一張書桌先後寫「一萬元」、「貳萬元」及「30,000 元」，卻沒有任何紀錄可判定原本合意的金額。

**正解：**若法院不能決定當事人原意，應以最低額一萬元為準。**依據：**民法第 5 條處理同一數量以文字或號碼數次表示而不符合的情形。

| 選項 | 解析 |
|---|---|
| **A. 以一萬元為準。** | **正確。**無法決定真意時採最低額。 |
| B. 以最後書寫的三萬元為準。 | 錯誤。條文未採最後記載優先。 |
| C. 以文字「貳萬元」為準。 | 錯誤。這不是文字與號碼各一次不符的第4條情形。 |
| D. 報價單當然無效。 | 錯誤。第5條提供補充判斷規則。 |

**申論提示：**比較民法第 4 條與第 5 條適用的事實差異。

## G-27｜海難後的失蹤親人

阿姨在颱風造成的海難中失蹤，事故結束已滿一年仍無消息。家人想處理她名下房屋與銀行帳戶。

**正解：**利害關係人得向法院聲請死亡宣告。**依據：**民法第 8 條第 3 項規定，遭遇特別災難者，特別災難終了滿一年後，得為死亡宣告。

| 選項 | 解析 |
|---|---|
| A. 必須等失蹤滿七年才能處理。 | 錯誤。特別災難有滿一年之特別規定。 |
| **B. 災難終了滿一年後，得向法院聲請死亡宣告。** | **正確。**但仍須由法院依聲請作成宣告。 |
| C. 家屬自行公告即可視為死亡。 | 錯誤。死亡宣告須由法院為之。 |
| D. 只要滿三個月就可聲請。 | 錯誤。第8條未規定三個月。 |

**申論提示：**比較一般失蹤、八十歲以上失蹤與特別災難失蹤的期間。

## G-28｜工作地租屋是否成為住所

小志在台中租屋工作三年，租約、工作與日常生活都在台中，並計畫長期居住；他仍在戶籍地保有父母家房間。

**正解：**應依具體事實判斷他是否有久住意思而在台中設定住所；法律上同時不得有兩住所。**依據：**民法第 20 條。

| 選項 | 解析 |
|---|---|
| **A. 要看久住意思與客觀居住事實，不只看戶籍或租約。** | **正確。**第20條採事實與久住意思的判斷。 |
| B. 只要租屋就必定有第二住所。 | 錯誤。一人同時不得有兩住所。 |
| C. 戶籍在哪裡，法律住所永遠只能在哪裡。 | 錯誤。條文以久住意思與居住事實判斷。 |
| D. 工作三年必定自動變更住所。 | 錯誤。仍須綜合事實認定。 |

**申論提示：**列出可用來判斷「久住意思」的三項客觀事實。

## G-29｜未成年人的法律住所

國中生小晴因讀書暫住外婆家，父母仍共同行使親權並住在新竹。某行政程序需要判斷她的法律住所。

**正解：**小晴以法定代理人住所為住所。**依據：**民法第 21 條。

| 選項 | 解析 |
|---|---|
| A. 以外婆住處當然為住所。 | 錯誤。暫住事實不改變第21條規定。 |
| **B. 以法定代理人的住所為住所。** | **正確。**限制行為能力人以法定代理人住所為住所。 |
| C. 未成年人沒有住所。 | 錯誤。法律明定其住所認定方式。 |
| D. 由未成年人自行選擇任一住處。 | 錯誤。不能自行任意選擇。 |

**申論提示：**若父母不能行使親權而由監護人擔任法定代理人，應如何分析？

## G-30｜讀書會能否自稱法人簽約

社區讀書會想租場地，成員在契約上寫「晨光基金會」並主張團體當然可以用法人名義承擔租金，但該團體未依任何法律完成法人設立程序。

**正解：**法人非依民法或其他法律規定不得成立，不能僅因自稱基金會就當然取得法人人格。**依據：**民法第 25 條。

| 選項 | 解析 |
|---|---|
| A. 只要有十位成員就當然成為法人。 | 錯誤。條文要求依法成立。 |
| B. 自稱基金會並對外活動即可成為法人。 | 錯誤。名稱與活動不是法人成立要件。 |
| **C. 必須依民法或其他法律規定成立，才是法人。** | **正確。**第25條採法律保留。 |
| D. 任何非營利團體都當然有法人格。 | 錯誤。非營利性不等於法人格。 |

**申論提示：**請說明「團體存在」與「法人已成立」為何不一定相同。
